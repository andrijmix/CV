RAG-агент для юридичних документів

  • Рішення: RAG-система та LangChain-агент для автоматичних відповідей на запитання за юридичними документами.

SuperAgent: мультиагентний RAG-чатбот

Модульний чат-агент, що спрямовує кожне запитання до потрібного спеціалізованого агента.

  • Проблема: один промпт не однаково добре відповідає на FAQ, неоднозначні та веб-запитання.
  • Рішення: маршрутизатор повідомлень розподіляє запити між FAQ Agent, Clarification Agent і Web Search Agent на LangChain / LangGraph; Elasticsearch (векторний пошук) для семантичного retrieval і збереження сесій чату.
  • Результат: робочий MVP на FastAPI з легким веб-інтерфейсом. Я спроєктував архітектуру, створив агентів, маршрутизатор і RAG-утиліти та написав документацію.

Стек: Python 3.10+, FastAPI, LangChain / LangGraph, Elasticsearch, OpenAI API

Autopilot: автономний політ на Visual Odometry

Тестове завдання при наймі в компанію з ПЗ для БПЛА, виконане в ArduPilot SITL: квадрокоптер виконує повну місію від зльоту до посадки, з режимом одометрії для польоту без GPS.

  • Проблема: автономно пролетіти з точки А в точку Б там, де GPS недоступний.
  • Рішення: 8-станова FSM місії, перемикане джерело навігації GPS / одометрія (локальна позиція EKF, розраховане на зовнішнє джерело Visual Odometry), PI/P-регулятори з компенсацією вітру, телеметрія DroneKit і failsafe-механізми (виявлення втрати GPS, таймаути станів, безпечне переривання).
  • Результат: повністю автономні місії в ArduPilot SITL, перевірені автоматизованим набором тестів PyTest.

Стек: Python, ArduPilot SITL, DroneKit, PyMAVLink, PyTest
