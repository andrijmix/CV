Голосовий AI-агент для колл-центру

Автоматично відповідає на дзвінки клієнтів за FAQ компанії. Створений в Anunciata.

  • Проблема: оператори витрачали час на повторювані FAQ-дзвінки.
  • Рішення: speech-to-speech агент на OpenAI gpt-4o-realtime: модель приймає аудіо дзвінка напряму й відповідає голосом, без окремого кроку STT чи TTS. Відповіді спираються на FAQ компанії через RAG на LangChain, а tool calling дає моделі виконувати безпечні запити до бази після авторизації.
  • Результат: обробляє ~100 дзвінків на день.

Стек: Python, OpenAI Realtime API (gpt-4o-realtime), LangChain, RAG, tool calling, speech-to-speech

RAG-агент для юридичних документів

LLM-агент, що відповідає на запитання за юридичними PDF. Ініційований і спроєктований самостійно.

  • Проблема: юристи переглядали юридичні PDF вручну.
  • Рішення: RAG-система та LangChain-агент для автоматичних відповідей на запитання за юридичними документами.
  • Результат: повністю прибрано людський фактор з перевірки документів. Оброблено сотні документів, якість відповідей оцінювалась автоматично за еталонною таблицею юристів, збіг ~90%.

Стек: Python, LangChain, RAG, обробка PDF

SuperAgent: мультиагентний RAG-чатбот

Модульний чат-агент, що спрямовує кожне запитання до потрібного спеціалізованого агента.

  • Проблема: один промпт не однаково добре відповідає на FAQ, неоднозначні та веб-запитання.
  • Рішення: маршрутизатор повідомлень розподіляє запити між FAQ Agent, Clarification Agent і Web Search Agent на LangChain / LangGraph; Elasticsearch (векторний пошук) для семантичного retrieval і збереження сесій чату.
  • Результат: робочий MVP на FastAPI з легким веб-інтерфейсом. Я спроєктував архітектуру, створив агентів, маршрутизатор і RAG-утиліти та написав документацію.

Стек: Python 3.10+, FastAPI, LangChain / LangGraph, Elasticsearch, OpenAI API

Стек: Python, FastAPI, SQLAlchemy, PostgreSQL, Celery, RabbitMQ, Redis, Vue 3, MCP, Playwright, GitHub Actions

Autopilot: автономний політ на Visual Odometry

Автономність у реальному часі: квадрокоптер виконує повну місію від зльоту до посадки, зокрема без GPS.

  • Проблема: автономно пролетіти з точки А в точку Б там, де GPS недоступний.
  • Рішення: 8-станова FSM місії, перемикане джерело навігації GPS / одометрія (інтеграція Visual Odometry для польоту без GPS), PI/P-регулятори з компенсацією вітру, телеметрія DroneKit і failsafe-механізми (виявлення втрати GPS, таймаути станів, безпечне переривання).
  • Результат: повністю автономні місії в ArduPilot SITL, перевірені автоматизованим набором тестів PyTest.

Стек: Python, ArduPilot SITL, DroneKit, PyMAVLink, Visual Odometry, PyTest
