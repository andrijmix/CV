Voice AI Agent for a Call Center

Answers client calls automatically using the company FAQ. Built at Anunciata.

  • Problem: operators spent their time on repetitive FAQ calls.
  • Solution: speech-to-speech agent on OpenAI gpt-4o-realtime: the model takes call audio directly and answers in voice with no separate STT or TTS step.   • Result: handles ~100 calls/day.

SuperAgent: Multi-Agent RAG Chatbot

A modular chat agent that routes each question to the right specialist agent.

  • Problem: one prompt cannot answer FAQ, ambiguous and open-web questions equally well.
  • Solution: a message router dispatches to a FAQ Agent, Clarification Agent or Web Search Agent, orchestrated with LangChain / LangGraph, with Elasticsearch vector search for retrieval and chat session storage.
  • Result: working MVP on FastAPI with a lightweight web interface. I designed the architecture, built the agents, router and RAG utilities, and wrote the docs.

Stack: Python 3.10+, FastAPI, LangChain / LangGraph, Elasticsearch, OpenAI API

Autopilot: Autonomous Flight with Visual Odometry

Real-time autonomy: a quadcopter flies a full mission from takeoff to landing, including without GPS.

  • Problem: fly autonomously from point A to point B where GPS is unavailable.
  • Solution: 8-state mission FSM, a switchable GPS / odometry navigation source (Visual Odometry integration for GPS-denied flight), PI/P controllers with wind compensation, DroneKit telemetry and failsafes (GPS-loss detection, state timeouts, graceful abort).
  • Result: fully autonomous missions in ArduPilot SITL, verified with an automated PyTest suite.

Stack: Python, ArduPilot SITL, DroneKit, PyMAVLink, Visual Odometry, PyTest
