Сайт доступний за адресою: [andrijmix.github.io](https://andrijmix.github.io)

## 📄 Сторінки

- [🇺🇦 Українська версія](https://andrijmix.github.io/index.html)
- [🇬🇧 English version (основна, для міжнародного ринку)](https://andrijmix.github.io/en.html)

## 📦 Структура проєкту

```
├── index.html           # Головна сторінка (українською)
├── en.html              # Англійська версія
├── css/styles.css       # Стилі для всіх сторінок
├── js/generatePDF.js    # Генерація PDF-файлу резюме (секції шукаються за data-pdf)
├── js/reveal.js         # Анімація появи блоків та лічильники
├── js/toggleDarkMode.js # Перемикач теми
├── photo.jpg            # Фото для профілю
├── README.md            # Цей файл
```

## ✏️ Як редагувати

Місця, де потрібні реальні цифри, позначені `<span class="ph">[? …]</span>` в обох HTML-файлах. Знайти всі: `grep -n 'class="ph"' *.html`.
